# 2026-11-02 修复 iOS example 构建失败（FlutterFramework 不存在）

- 根因1：插件声明了 SPM（ios/amap_maps_flutter_qs/Package.swift 依赖 ../FlutterFramework），但 AMap3DMap SDK 仅 CocoaPods 分发；example ephemeral 陈旧导致 xcodebuild 解析 ios/FlutterFramework 失败。
- 修复1：删除插件 Package.swift，回归 podspec（CocoaPods）集成；flutter clean + pub get 重建 ephemeral。
- 根因2：example Podfile 无 platform 声明 + use_frameworks! 动态链接与 MAMapKit 静态框架冲突。
- 修复2：Podfile 加 `platform :ios, '15.0'`，删除 use_frameworks!。
- 根因3：AMapPlatformView.swift 按 SDK 9/10 API 编写，从未编译通过。
- 修复3（SDK 11.2 迁移）：import MAMapKit（非 AMap3DMap）；setPolylineWithCoordinates/setPolygonWithCoordinates（数组需 & 桥接）；SDK 11.2 移除 interiorPolygons，iOS 暂不支持 polygon holes；isShowTraffic/isShowsBuildings/isShowsLabels；MAMapStatus(center:)；convert(_:toCoordinateFrom:)；委托回调改名 didSingleTappedAt/didLongPressedAt/didChange；MAPolylineRenderer 等初始化器变为可失败；虚线用 kMALineDashType* 全名常量。
- 结果：flutter build ios --debug --no-codesign 成功。
- 注意：AMap SDK 无 arm64 模拟器 slice，需真机调试；swiftc -typecheck + -F Pods 路径可快速验证 API 签名，比全量构建快得多。

# 2026-11-02 修复 MissingPluginException（didUpdateWidget 竞态）

- 现象：iOS 模拟器运行 example，切换地图类型/手势开关时抛 MissingPluginException（map#setMapType / map#setGestures on channel amap_maps_flutter_qs/map#0），地图本身可显示。
- 根因：iOS UiKitView（及 Android initExpensiveAndroidView）异步创建，build() 返回后原生 AMapPlatformView（map#<id> 通道 handler 注册方）尚未存在，此期间 didUpdateWidget 直发通道调用必然 MissingPluginException。
- 修复（lib/src/widget/amap_widget.dart）：仿 google_maps_flutter —— _AMapWidgetState 增加 _platformViewCreated 标志 + _pendingCalls 队列；didUpdateWidget 统一走 _invokeMapMethod（未创建则入队）；framework onPlatformViewCreated（Android addOnPlatformViewCreatedListener / iOS UiKitView.onPlatformViewCreated）与原生 mapCreated 双路径幂等置位并按序冲刷；dispose 清空队列；invokeMethod 捕获 MissingPluginException 静默丢弃（地图已销毁的迟到调用）。
- 验证：flutter analyze 无问题；flutter test 96 通过 / 1 失败 —— 失败的 tmp_render_probe_test.dart 为离屏像素探针、不 import 插件代码，与本次改动无关（历史遗留）。
- 另：地图空白最初还叠加了未配 key（demo_config.dart 占位符）与模拟器断网（adiu.amap.com offline）两个因素。
